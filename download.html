Installing

Two minutes, and one folder you should not break

  • Run the installer and follow the wizard — it offers English and Tiếng Việt, creates the shortcuts and adds an uninstall entry.
  • Using a ZIP instead? Unzip the whole folder and run PianoPath.exe from inside it. The SoundFont has to sit next to the executable, and the licence files travel with it.
  • Keep LICENSE.txt (MIT) and Assets\ATTRIBUTION.txt (the SoundFont's CC BY 3.0) when you pass a copy on to somebody else.

Windows SmartScreen will warn you once

The packages are not code-signed, so the first launch shows “Windows protected your PC”. Choose More info, then Run anyway. Signing is on the project's list; until then, the checksum is how you confirm the file you received is the file the pipeline built.

Checking a download

Compare the hash against SHA256SUMS.txt

PowerShell
# what you received
Get-FileHash .\Keyflow-Setup-1.0.0.exe -Algorithm SHA256

# what the release says it should be
Get-Content .\SHA256SUMS.txt

The two hashes have to match exactly. A mismatch means the download was altered or truncated — delete it and take the file from the release page again.

What is in 1.0.0

The first official release

One entry in the changelog describes the product as released — these are the parts a user meets first.

GPU engine by default

A Direct3D 11 stage on its own thread with HDR, bloom and a frame-rate target up to 240 FPS; the WPF renderer became the fallback.

Shading every frame

The 88-key keyboard is shaded in HLSL on the GPU stage, with the dock's sliders applied per frame.

MP4 with the sound inside

Media Foundation writes H.264 video and AAC audio into one file, with a bitrate derived from size and frame rate.

A staff layer on the stage

Key signature inferred from the song, beaming, rests, ties, chords as one column and hand-change curves.

Library, history and ghost

A folder library with tags and a watcher, per-run practice history, a fourteen-day chart and your best take drawn as a ghost.

Themes you can build

A theme studio deriving twenty tokens from five colours, a community preset shelf, rendered preset thumbnails and one-line share codes.

Two languages, checked

English and Tiếng Việt switch live, the dock search answers in both, and a static check proves the tables carry the same keys.

Accessibility & verification

Named glyph buttons, Tab cycling inside the dock, Windows high contrast support, and a verification suite you can run yourself.

Four packages

An installer, a self-contained ZIP, a framework-dependent ZIP and an ARM64 ZIP, each with SHA-256 checksums.

Before you install

Download questions

Which package should I take?
The installer for a normal Windows PC — it is self-contained, so no runtime to install. Take the portable ZIP if you prefer to keep it on a stick or in a folder of your own, the framework-dependent ZIP if you already have the .NET 10 Desktop Runtime and want a smaller download, and the ARM64 ZIP on Windows on ARM — knowing it has not been run on real ARM hardware yet.
Is it really free? Where is the catch?
The code is MIT licensed and the packages cost nothing. There is no account, no sign-in, no telemetry and no upsell inside the app. The bundled piano is FreePats' YDP Grand under CC BY 3.0, credited in every package.
Will my antivirus or Windows complain?
SmartScreen warns once because nothing is code-signed: More info → Run anyway. The release carries SHA256SUMS.txt so you can verify the file yourself, and PianoPath.exe --verify runs the built-in checks on your own machine and prints PASS or FAIL per subject.
Does it work on an old PC with no graphics card?
It runs: Keyflow falls back to WARP, Windows' software rasterizer executing the same shaders, and then to the WPF renderer if Direct3D cannot start. Expect a lower frame rate on heavy presets — a heavy frame costs FPS, never MIDI latency.
Where do I report a bug?
On GitHub Issues. Attach a screenshot, the profile you exported from General → SETTINGS PROFILE, and the log from --verify --verify-log=… — that is usually enough to reproduce it.
