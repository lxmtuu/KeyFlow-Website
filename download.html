Installing

Two minutes, and one download after it

  • Run the installer and follow the wizard — it offers English and Tiếng Việt, creates the shortcuts and adds an uninstall entry.
  • Using a ZIP instead? Unzip the whole folder and run PianoPath.exe from inside it. The licence file travels with it, and there is nothing else in the folder to keep together.
  • Open the app, then SETTINGS → Audio → Download piano · 748 MB for the one-time sample install. Every file is verified as it arrives, a cancelled download resumes, and the piano loads itself when the last file checks out.
  • Keep LICENSE.txt (MIT) when you pass a copy on to somebody else; the piano's CC BY 3.0 notice is written beside the samples in the piano data folder.

Windows SmartScreen will warn you once

The packages are not code-signed — SignPath Foundation declined the project's application, so 2.0.1 ships the builds and the installer unsigned. The first launch shows “Windows protected your PC”: choose More info, then Run anyway. Until SignPath (or another signature) is in place, the checksum is how you confirm the file you received is the file the pipeline built.

Checking a download

Compare the hash against SHA256SUMS.txt

PowerShell
# what you received\nGet-FileHash .\Keyflow-Setup-2.0.1.exe -Algorithm SHA256\n\n# what the release says it should be\nGet-Content .\SHA256SUMS.txt

The two hashes have to match exactly. A mismatch means the download was altered or truncated — delete it and take the file from the release page again.

What is in 2.0.1

Two releases, one big step — and a small polish on top

2.0.1 is a shorter entry and 2.0.0 the long one: together they describe everything a user meets in this build.

AR overlay on your own keyboard

Mark the four corners of the key strip and the notes fall onto the real keys, in perspective — with a Unity-style Move/Rotate/Scale gizmo, a quality budget, an alignment check and a drift watch.

Salamander Grand Piano V3, sole instrument

A Yamaha C5 recorded at 48 kHz/24-bit by Alexander Holm, rendered through SFZ: 641 FLAC files, about 748 MB, downloaded once on request — no SF2 import, no instrument picker, no samples in Git or the packages.

Your audio path, your room

WASAPI shared/exclusive, an ASIO driver or waveOut, with gain, a hall reverb, a convolution reverb (built-in rooms or your own impulse response) and always-on string resonance.

88, 76, 61 or 49 keys

Pick the size that matches the instrument in front of you; the stage, the falling notes, the lit keys and the GPU engine all follow it, and presets leave it alone.

A camera list that tells the truth

One line per camera with its real name, kind, port and VID/PID; the app picks the mode nearest 720p at up to 60 fps, reads at the camera's own pace, and remembers the camera delay per camera.

Live press bars, and a look that carries its graphs

Press bars stay independent and off by default, with a 25–300% Bar coverage slider and an optional lifetime fade; share codes are now KEYFLOW-LOOK-2: and carry the AR graphs with the palette, while version-1 codes still open bit for bit.

An interface of icon buttons

The wall of all-caps labels is gone from the settings dock, the header and the start menu; glyph buttons carry localized tooltips, which are also the names screen readers announce.

A start menu that splits the setup

Piano & Audio Setup and MIDI Devices open their settings pages straight away, Quick Adjustments keeps the most-used stage controls, and Stage Design Studio opens the full dock.

Still MIT, still unsigned

Four packages and a checksum file, the same verification suite inside the app, and an honest note: SignPath Foundation declined the application, so SmartScreen will warn once until the project is signed.

Before you install

Download questions

Which package should I take?
The installer for a normal Windows PC — 48.8 MiB and self-contained, so no runtime to install. Take the portable ZIP if you prefer to keep it on a stick or in a folder of your own, the framework-dependent ZIP (2.7 MiB) if you already have the .NET 10 Desktop Runtime, and the ARM64 ZIP on Windows on ARM — knowing it has not been run on real ARM hardware yet.
Why is the download so small, and why does the app ask for 748 MB?
Since 2.0.0 the samples are no longer bundled: shipping 748 MB of piano in Git, in every ZIP and in every installer would be paid for by every download, including the people who never open the Audio page. The installer is 48.8 MiB instead, and the app fetches the library once, on request, verifying each file and resuming after a cancel.
Is it really free? Where is the catch?
The code is MIT licensed and the packages cost nothing. There is no account, no sign-in, no telemetry and no upsell inside the app. The piano is Salamander Grand Piano V3 by Alexander Holm under CC BY 3.0 — its attribution is written beside the samples, and kept even though the samples are not redistributed with the app.
Will my antivirus or Windows complain?
SmartScreen warns once because nothing is code-signed: More info → Run anyway. The release carries SHA256SUMS.txt so you can verify the file yourself, and PianoPath.exe --verify runs the built-in checks on your own machine and prints PASS or FAIL per subject.
Does it work on an old PC with no graphics card?
It runs: Keyflow falls back to WARP, Windows' software rasterizer executing the same shaders, and then to the WPF renderer if Direct3D cannot start. Expect a lower frame rate on heavy presets — a heavy frame costs FPS, never MIDI latency.
Where do I report a bug?
On GitHub Issues. Attach a screenshot, the profile you exported from General → SETTINGS PROFILE, and the log from --verify --verify-log=… — that is usually enough to reproduce it.
